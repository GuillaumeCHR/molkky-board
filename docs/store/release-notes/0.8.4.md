# Notes de version 0.8.4 (build 12) — test fermé

Changements depuis la 0.8.2 (dernière version envoyée en test fermé). Limite Play : 500 caractères par langue.

<en-US>
- Tablets, foldables and Chromebooks: centred layout, two-column game screen in landscape
- Phones stay in portrait; larger screens can rotate freely
- Pin grid centred on the game screen
- "Ready to play?" no longer shows on a guest phone
- New "Send feedback" button in About: tell us what works and what doesn't!
</en-US>
