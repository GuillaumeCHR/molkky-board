# Sécurité

Merci de signaler toute vulnérabilité de Molkky Board de façon **privée**, par e-mail à **yogistudiofr@gmail.com**
(objet : « Sécurité Molkky Board »), plutôt que par une *issue* publique.

Indiquez la version de l'app, le modèle et la version d'Android, et les étapes pour reproduire. Vous recevrez un
accusé de réception, et le correctif sera publié dans une nouvelle version. Merci de laisser un délai raisonnable
avant toute divulgation publique.

Versions concernées : la dernière version publiée.
